# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Expanded semantic color palette with theme-aware core components
- Runtime light/dark theme example
- Main-axis and cross-axis alignment for `Row` and `Column`

## [0.3.1] - 2026-08-20

### Changed

- Updated `gioui.org` from v0.9.0 to v0.10.2
- Updated indirect dependencies (`golang.org/x/*`, `go-text/typesetting`, etc.)
- Raised minimum Go version to 1.26.0
- Removed unused `gioui.org/x` direct dependency

## [0.3.0] - 2026-01-02

### Added

- `Image` and `ScrollView` widgets

## [0.2.0]

### Added

- Outline variant for `Button`
- Buttons example

## [0.1.0]

### Changed

- Improved README example
